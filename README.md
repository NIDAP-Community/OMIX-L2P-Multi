# L2P Analysis (Single)

## Description
L2P (Likely2Protein) analysis for gene likelihood assessment. Analyzes gene lists to determine protein-coding likelihood using ortholog databases and statistical methods.

## Usage
This capsule performs L2P analysis on input gene data.

## Structure
- `code/functions/L2P_Analysis.R` - Main analysis function
- `code/main.R` - Entry point that loads and executes the analysis
- `code/run` - Bash script for reproducible execution

## Outputs
Results are written to `/results/` directory.
